# Sheikh Farhan Khan: portfolio (React + Vite, GitHub Pages)
Run: `npm install`, `npm run dev`. Build: `npm run build`. All content is in `src/data/profile.js`.

## HOW TO UPDATE LATER
**Photo:** replace `public/assets/images/profile.jpeg` (same filename). A photo with the face in the upper half works best.
**Add a project:** copy a block in `projects` in `src/data/profile.js` and edit it. `cat` options: AI / ML, GenAI, GeoINT, IoT, Aquaculture, Engineering.
**Skills / education / experience:** edit `skills`, `education`, `experience` in the same file.
**Deploy:** commit and push to `main`. Pages source must be "GitHub Actions". Site: https://farhankhan1625.github.io/farhankhan1625/
There is no resume download on the site by design.
